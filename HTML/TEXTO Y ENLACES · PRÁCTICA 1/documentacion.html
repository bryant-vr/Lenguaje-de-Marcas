Introducción

WeatherAPI permite consultar el tiempo actual y la previsión de distintas ciudades mediante peticiones HTTP que devuelven datos en formato JSON.

Consultar la documentación oficial de WeatherAPI

Autenticación

Todas las peticiones requieren una clave de API que se envía en la cabecera de cada solicitud. Sin ella, la API devolverá un error de acceso.

Leer la política de seguridad de WeatherAPI

Endpoint de usuarios

Permite crear, consultar y gestionar los usuarios que tienen acceso a la API.

Endpoint de ciudades

Permite buscar ciudades y obtener su información meteorológica a partir de su nombre.

Contacto

Para dudas o incidencias sobre la API, escribe al equipo de soporte de WeatherAPI.
